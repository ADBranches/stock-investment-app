# Project Scope

## Project Name
Stock Investment App

## Project Summary
Stock Investment App is a mobile-first fintech product designed to help users learn about investing, discover financial assets, build watchlists, monitor portfolio performance, and execute guided trade actions in a secure and beginner-friendly environment.

## Problem Being Solved
Many potential investors, especially first-time and younger users, struggle with:
- low investment literacy
- overwhelming trading interfaces
- lack of trust in digital investment tools
- poor onboarding experiences
- limited guidance around responsible investing
- weak visibility into personal portfolio progress

This project addresses those issues through a modern, accessible, and guided investment experience.

## In-Scope Features

### MVP Scope
- splash and onboarding
- sign up
- login
- logout
- persistent authentication
- profile setup
- KYC submission UI
- dashboard
- market asset listing
- asset details
- watchlist
- portfolio overview
- buy/sell simulation or controlled trade request flow
- transaction history
- backend API integration

### Post-MVP Scope
- education hub
- real-time notifications
- biometric authentication
- advanced analytics
- personalized recommendations
- production-grade compliance workflows
- funding and withdrawal flows
- multi-device session management

## Target Users
- beginner investors
- young professionals
- students and first-time earners
- users seeking guided investing experiences
- users who need a secure and trustworthy mobile platform

## Product Goals
- reduce friction in the investment journey
- make investing approachable
- support responsible investor behavior
- present markets visually and clearly
- create a trustworthy mobile experience
- deliver a scalable fintech foundation

## Success Criteria
The MVP is successful when a user can:
1. install and open the app
2. onboard into the product
3. create an account or log in
4. complete a profile setup flow
5. submit KYC details
6. browse assets
7. view asset detail pages
8. add or remove assets from a watchlist
9. see a portfolio summary
10. place a simulated or controlled buy/sell action
11. remain authenticated across sessions

## Constraints
- Android-first delivery
- MVP limited to core investing flow
- real trading infrastructure deferred until post-MVP
- backend designed for future expansion
