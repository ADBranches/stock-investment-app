# Wireframes and Design Direction

## Goal
This folder stores the product design baseline for the mobile app.

## Design Principles
The interface must be:
- elegant
- modern
- clean
- investor-trustworthy
- beginner-friendly
- visually competitive with polished startup apps

## Visual Direction
We want the app to feel close to premium React + Tailwind products in terms of:
- spacing
- card structure
- hierarchy
- modern gradients
- rich dark/light sections
- clean CTA buttons
- sleek dashboards
- polished empty states
- premium onboarding screens

## Initial Screen Set

## Design Notes
- use bold headings
- use cards generously
- use soft corner radius
- use trust-oriented colors
- show market data clearly
- prefer premium spacing over clutter
- use modern metrics blocks and dashboard summaries
- maintain visual consistency from onboarding to portfolio

## Expected Design Tools
- Figma for wireframes and polished mockups
- Android Studio Compose for implementation reference later

## Output Standard
Designs should look market-ready, demo-ready, and investor-pitch ready.
