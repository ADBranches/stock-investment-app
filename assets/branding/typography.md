# Typography

## Brand Typography Direction
Typography must feel:
- bold
- clean
- premium
- highly legible
- modern

## Preferred Font Style
Use Android-friendly modern sans-serif typography that feels similar in tone to:
- Inter
- Manrope
- Sora
- General Sans

For implementation, use a clean Android-supported alternative or bundled font family that preserves a modern startup feel.

## Typography Hierarchy

### Display Large
- Use for splash screen hero statements
- Large bold confident headings

### Headline
- Use for dashboard titles, onboarding titles, asset names

### Title
- Use for section headers, card titles, detail screen headings

### Body
- Use for descriptions, helper text, education copy

### Label
- Use for chips, form field labels, badges, buttons

## Typography Rules
- use strong heading contrast
- avoid cramped spacing
- maintain clean line height
- keep labels readable
- make financial data easy to scan
- prioritize clarity over decoration

## Product Feel
Text should make the app feel like a serious investment product, not a student demo.
